## 📌 Sobre o Projeto

Este projeto foi desenvolvido em **2021** durante minha formação em Business Intelligence.

O objetivo foi criar um dashboard executivo para análise comercial de uma empresa exportadora, permitindo acompanhar indicadores estratégicos, desempenho de vendas, faturamento e resultados por diferentes dimensões do negócio.

Mesmo sendo um dos meus primeiros projetos em Power BI, ele representa o início da minha jornada na área de Dados e demonstra minha evolução em modelagem, visualização de dados e criação de dashboards para tomada de decisão.

---

## 🎯 Objetivos

- Transformar dados brutos em informações estratégicas.
- Criar um dashboard intuitivo para acompanhamento comercial.
- Facilitar a análise de vendas e faturamento.
- Utilizar recursos visuais para apoiar a tomada de decisão.
